# Laboratory experiment sprites

Five standalone transparent PNG sprites generated from the IGNIS laboratory scene as visual reference. These are concept/game-art assets, not scientific diagrams.

- `experiment-chamber.png` — central containment chamber and plasma core
- `analysis-bench.png` — modular sample-analysis bench
- `control-console.png` — multi-screen laboratory console
- `gas-cylinder-rack.png` — four-cylinder storage rack
- `scientist.png` — standing technician with handheld tablet

All images are RGBA with alpha transparency. The scientist includes a soft ambient glow around the silhouette; inspect at intended in-game scale before use. Source scene: `design/assets/estaleiros/laboratorio_experimentos/mapa_laboratorio_experimentos_v1.png` in the parent NASA workspace.
