# Takes do hangar IGNIS

Assets preparados para uso como fundos de takes no protótipo PixiJS (`HangarScene`).

- `hangar_take_02_maintenance.png` — inspeção e manutenção da nave no pad.
- `hangar_take_04_departure.png` — nave deixando o hangar.

São ilustrações de cena para prototipagem; não são spritesheets nem animações quadro a quadro. O cenário base para a cena interativa continua em `hangar_bg.jpg`, com metadados de spritesheet em `spritesheet_spec.json`.
